# Замер скорости скачивания

Консольный скрипт на TypeScript принимает URL и выполняет 10 последовательных GET-запросов. Каждый следующий запрос начинается после полного чтения предыдущего ответа. Скрипт считает байты по мере загрузки и показывает ход каждого запроса. Если сервер сообщил размер ответа, рядом с объёмом отображается процент.

После десяти загрузок скрипт выводит таблицу с номером, методом, URL, временем и объёмом каждого запроса. Ниже отображаются среднее время, общий объём и скорость скачивания.

## Запуск на GitHub

1. Открой [Замер скорости в GitHub Actions](https://github.com/BorisenkoDmitry/test_picture/actions/workflows/speedtest.yml).
2. Нажми **Run workflow**. Для ручного запуска нужны права на запись в репозиторий.
3. Оставь поле `url` пустым, чтобы использовать тестовый JPEG с httpbin.org, или укажи публичный HTTPS-адрес файла. Подтверди запуск кнопкой **Run workflow**.
4. Открой свежий запуск, выбери задачу **speedtest** и раскрой шаг **Замер скорости**. В журнале появятся ход загрузки, таблица и итоговые показатели.

GitHub запускает скрипт на своём сервере без скачивания проекта на твой компьютер. Замер показывает скорость от сервера GitHub до выбранного адреса. Запускай его локально, чтобы измерить скачивание со своего компьютера.

## Запуск на компьютере

Понадобятся Git и Node.js 20 или новее. После клонирования запусти из папки проекта.

```bash
npm ci
npm start
```

Передай собственный адрес после `--` или включи автоматический перезапуск при сохранении файлов.

```bash
npm start -- "https://example.com/file.jpg"
npm run dev
```

В PowerShell команды можно запускать через `npm.cmd`, например `npm.cmd start`. Для остановки режима отслеживания нажми `Ctrl+C`.

## Как считаются показатели

- **Среднее время запроса (мс)** — сумма длительностей, делённая на 10. Длительность измеряется от начала GET до конца чтения тела ответа и включает ожидание сервера.
- **Общий объём (байты)** — сумма байтов тел всех десяти ответов. Скрипт запрашивает передачу без HTTP-сжатия. Если сервер всё равно присылает сжатый ответ, учитываются байты после распаковки.
- **Скорость скачивания (Мбит/с)** — общий объём в байтах × 8 ÷ суммарное время в секундах ÷ 1 000 000.

Для каждого запроса установлен тайм-аут 30 секунд. При ошибке скрипт выводит номер запроса и причину остановки.

В `src/get.ts` находится потоковая загрузка, в `src/measure.ts` — цикл запросов и расчёт статистики, в `src/index.ts` — обработка аргумента и вывод результата.
